# 桌面端视觉规范

> 本文是已定稿的桌面端视觉规则，实现落在 `desktop/renderer/ui/`（`tokens.css` + 组件）。
> 与效果图有出入时，先看 `desktop/renderer/ui/README.md` 的「与定稿效果图的偏差」，再改本文。
> 规范之外不要自造 token；要改视觉，先改本文并让改动可复核。

## 1. 层次

窗口材质底 → 侧栏玻璃 → 纸面板 → 白卡。

- **内容层永远不透明**：表头、数据行、收口条、日志、表单整块都要在卡里；
  页面级注释（如「账户用于登录 Web 端和 GUI」、备份页警告条）才允许直接放在纸面上。
- **玻璃只出现在导航层**：侧栏、对话框、Toast。正文不要用半透明或模糊。
- 底色是中性灰，**不用彩色渐变**。浅色窗口底 `#F1F1F3 → #EFEFF1`，深色 `#171719 → #151517`。

## 2. 判据

- 高级感来自秩序和精度，不来自颜色。画面空就加结构（发丝线、对齐、字阶），不要加渐变。
- 玻璃的可信度由四样东西凑齐：顶部 1px 镜面高光、外亮内暗双线、中性极细噪声（1× 不可见、2× 可见）、
  纸面板的圆角与投影。缺一样就退回塑料。
- **主题对位（theme parity）**：同一条边缘线索在浅色/深色下的 CIE L\* 差（ΔL）必须落在 ±1 个百分点内。
  浅色靠压暗表达边缘（如顶部 1px 黑 8.5%，ΔL −4.9），深色靠提亮（白 3.4%，ΔL +5.2）。
  不要给两种主题同一个颜色值：同一个 token 在两种底色上的感知强度能差 13 个 ΔL。
- `inset` 阴影在外层带 `backdrop-filter` 的元素上不渲染，边缘线必须用真 `border`；
  颗粒层的 `::after` 用 `inset: 2px` 让开 1px 边线，否则会把线冲淡。

## 3. 尺寸

画布 1280×800；侧栏 240；内容左右留白 32；卡片圆角 12；卡片内边距 20；
表格数据行高 44；正文 13/20；页面标题 22/600；字段标签 12/18 用次级文字色。

## 4. 各页面的既定结论

| 位置                  | 结论                                                                                                                                 |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 侧栏选中态            | `rgba(0,0,0,.06)` 填充 + 图标用强调色，文字保持中性，无描边                                                                          |
| 表格页（账户 / 备份） | 撑满剩余高度，底部收口条，刻意留一点空白                                                                                             |
| 备份页                | 服务运行中时「立即备份」「恢复」禁用 + 顶部警告条 +「去停止」                                                                        |
| 日志区                | 普通白卡，不是下陷块：卡内「最近日志 / 清屏」+ 发丝线 + 等宽行（行间无分隔线）+「共 N 行」收口；无灰底、无内阴影、无边框             |
| 日志文字              | `--log-fg` `#5C5C63`、`--log-dim` `#64646B`（深色 `#95959B`）；INFO `#0B62C4`、WARN `#8A5800`、ERROR `#C42B1C`，白卡底上全部 ≥ 4.5:1 |

## 5. 怎么核对

组件与样张都在仓库里，不需要另外的效果图：

```sh
./node_modules/.bin/rspack build -c desktop/rspack.config.ts
google-chrome --headless=new --no-sandbox --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=1280,800 \
  --screenshot=tmp/gallery-light.png \
  file://$PWD/desktop/dist/renderer/gallery.html
```

`#dark` 深色、`#density` 纸面视图、`#dark-density` 深色纸面视图；页面右上角也能切。
改完组件先对总览页，再对具体页面。
